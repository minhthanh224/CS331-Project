# SAM + CAM for Weakly Supervised Semantic Segmentation (WSSS)
A research and learning project exploring the combination of Class Activation Mapping (CAM) and the Segment Anything Model (SAM) for weakly supervised semantic segmentation (WSSS).
## Research Goals
We aim to evaluate different combinations of CAM and SAM models and investigate improvements informed by relevant research papers.
## Planned Comparisons
The initial experiments will compare:
- CAM only
- CAM + denseCRF
- CAM (base) + SAM (base)
